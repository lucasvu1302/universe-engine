## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- [pnpm](https://pnpm.io/) 9+

### Quickstart (Zero Configuration Needed)
```bash
# Clone the repository
git clone https://github.com/lucasvu1302/universe-engine.git

# Navigate into the project folder
cd universe-engine

# Install dependencies
pnpm install

# Start local dev server at http://localhost:3000
pnpm dev
```

### Build & Verification
```bash
pnpm typecheck   # TypeScript check (0 errors)
pnpm lint        # ESLint check (0 warnings)
pnpm test        # Vitest unit test suite (12/12 pass)
pnpm test:e2e    # Playwright E2E suite (14/14 pass)
pnpm build       # Fast production build (143ms)
```
